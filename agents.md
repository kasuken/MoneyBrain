## MCP Server Configuration

For GitHub Copilot Workspace users, MCP servers require user-level configuration:

- **Setup Guide**: [.github/COPILOT_WORKSPACE_MCP_SETUP.md](.github/COPILOT_WORKSPACE_MCP_SETUP.md)
- **VS Code Config**: `.vscode/mcp.json` (works automatically in VS Code)
- **Workspace Config**: See setup guide above

The `.vscode/mcp.json` file contains the MCP server definitions but is only read by VS Code. GitHub Copilot Workspace requires the configuration to be placed in your user home directory.
