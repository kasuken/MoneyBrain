This directory should contain screenshots for the PWA app store listings.

## Required Screenshots

### Desktop (Wide)
- `dashboard-desktop.png` - 1280x720 pixels
  - Screenshot of the MoneyBrain dashboard on desktop
  - Should show key features and clean UI

### Mobile (Narrow)
- `dashboard-mobile.png` - 750x1334 pixels
  - Screenshot of dashboard on mobile device
  - Should demonstrate mobile responsiveness

## Guidelines

### Desktop Screenshots (1280x720+)
- Use Chrome/Edge with a 1920x1080 window
- Capture clean, organized views
- Avoid showing personal/sensitive data
- Show actual features in use

### Mobile Screenshots (750x1334 or 1242x2208)
- Use Chrome DevTools device emulation (iPhone X/11/12)
- Or use actual device screenshots
- Portrait orientation preferred
- Show responsive design benefits

## How to Capture

1. **Desktop:** Use browser screenshot tools or Snipping Tool
2. **Mobile:** 
   - Chrome DevTools > Device Toolbar > Capture screenshot
   - Or use actual devices
3. **Tools:** 
   - Windows: Win + Shift + S
   - Mac: Cmd + Shift + 4
   - Chrome: F12 > Device Mode > Screenshot icon

## Purpose

Screenshots are shown in:
- Installation prompts on some platforms
- App stores (if listed)
- PWA catalog sites
- Marketing materials

## Validation

Preview screenshots in:
- Chrome DevTools > Application > Manifest
- https://www.pwabuilder.com/
- Microsoft Edge PWA builder
